## Question

What happens when a view calls `abort(404)`, and how does it reach the registered error handler?

## Reference answer

When abort(404) is called, it uses current_app.aborter to raise a NotFound HTTP exception. This exception reaches handle_user_exception, which passes HTTP errors to handle_http_exception. That method then looks up a registered error handler for the 404 status and calls it, or simply returns the error itself as the response if no handler is registered.
