## Question

Why does `flash()` copy the stored messages list and assign it back to the session, instead of appending to it in place?

## Reference answer

flash() copies the stored messages list and assigns it back to the session because the old in-place append method failed to update session backends that store data externally. Reassigning the list explicitly marks the session as modified so that external backends know to save the changes.
