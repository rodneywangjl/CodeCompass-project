## Question

How does the tagged JSON serializer class that handles bytes maintain data consistency and reversibility when encoding binary data through base64?

## Reference answer

The tagged JSON serializer class that handles bytes (TagBytes) maintains data consistency and reversibility through several mechanisms:

1. **Coupled encoding/decoding in the same class**: Both the encoding (`to_json`) and decoding (`to_python`) methods are implemented in the same class (`src/flask/json/tag.py`, lines 159-170). This ensures they use the same base64 encoding scheme:
   - `to_json()`: Encodes bytes using `b64encode(value).decode("ascii")` to produce a JSON-compatible ASCII string
   - `to_python()`: Decodes the base64 string back to bytes using `b64decode(value)`

2. **Tag-based identification system**: The class uses the key `" b"` to wrap encoded data as `{" b": <base64_string>}` during serialization (via the `tag()` method inherited from JSONTag, line 90). During deserialization, the TaggedJSONSerializer's `untag()` method (lines 297-307) recognizes this key and routes the value to the correct `to_python()` method, ensuring the encoded data is properly identified and decoded.

3. **Base64 reversibility**: Base64 encoding is mathematically reversible, ensuring that `b64decode(b64encode(data)) == data` for any binary input.

4. **ASCII decoding for JSON compatibility**: The `.decode("ascii")` step in `to_json()` ensures the encoded data is a valid JSON string type, since JSON cannot directly represent binary data (as noted in `docs/patterns/javascript.rst`, line 235).

5. **Integrated serialization lifecycle**: The encoding and decoding are tightly integrated through TaggedJSONSerializer's `dumps()` and `loads()` methods:
   - `dumps()` calls `tag()` which wraps the base64-encoded string with the tag key
   - `loads()` calls `_untag_scan()` which recursively finds tagged dicts and calls `untag()` to decode them

This design ensures that bytes data can be round-tripped through JSON serialization without loss, as demonstrated by the test in `tests/test_json_tag.py` (line 29) where `s.loads(s.dumps(b"\xff")) == b"\xff"`.

class JSONTag:
    """Base class for defining type tags for :class:`TaggedJSONSerializer`."""

    __slots__ = ("serializer",)

    #: The tag to mark the serialized object with. If empty, this tag is
    #: only used as an intermediate step during tagging.
    key: str = ""

    def __init__(self, serializer: TaggedJSONSerializer) -> None:
        """Create a tagger for the given serializer."""
        self.serializer = serializer

    def check(self, value: t.Any) -> bool:
        """Check if the given value should be tagged by this tag."""
        raise NotImplementedError

    def to_json(self, value: t.Any) -> t.Any:
        """Convert the Python object to an object that is a valid JSON type.
        The tag will be added later."""
        raise NotImplementedError

    def to_python(self, value: t.Any) -> t.Any:
        """Convert the JSON representation back to the correct type. The tag
        will already be removed."""
        raise NotImplementedError

    def tag(self, value: t.Any) -> dict[str, t.Any]:
        """Convert the value to a valid JSON type and add the tag structure
        around it."""
        return {self.key: self.to_json(value)}

    def register(
        self,
        tag_class: type[JSONTag],
        force: bool = False,
        index: int | None = None,
    ) -> None:
        """Register a new tag with this serializer.

        :param tag_class: tag class to register. Will be instantiated with this
            serializer instance.
        :param force: overwrite an existing tag. If false (default), a
            :exc:`KeyError` is raised.
        :param index: index to insert the new tag in the tag order. Useful when
            the new tag is a special case of an existing tag. If ``None``
            (default), the tag is appended to the end of the order.

        :raise KeyError: if the tag key is already registered and ``force`` is
            not true.
        """
        tag = tag_class(self)
        key = tag.key

        if key:
            if not force and key in self.tags:
                raise KeyError(f"Tag '{key}' is already registered.")

            self.tags[key] = tag

        if index is None:
            self.order.append(tag)
        else:
            self.order.insert(index, tag)

class TagDict(JSONTag):
    """Tag for 1-item dicts whose only key matches a registered tag.

    Internally, the dict key is suffixed with `__`, and the suffix is removed
    when deserializing.
    """

    __slots__ = ()
    key = " di"

    def check(self, value: t.Any) -> bool:
        return (
            isinstance(value, dict)
            and len(value) == 1
            and next(iter(value)) in self.serializer.tags
        )

    def to_json(self, value: t.Any) -> t.Any:
        key = next(iter(value))
        return {f"{key}__": self.serializer.tag(value[key])}

    def to_python(self, value: t.Any) -> t.Any:
        key = next(iter(value))
        return {key[:-2]: value[key]}
