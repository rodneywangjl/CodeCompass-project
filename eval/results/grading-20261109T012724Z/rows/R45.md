## Question

There's a `sansio` folder next to `app.py` and `blueprints.py`. Which parts of `Flask` and `Blueprint` live there, and which classes add the rest?

## Reference answer

`sansio` holds the base classes that do no I/O: `App` in `sansio/app.py` and the base `Blueprint` in `sansio/blueprints.py`, both built on `Scaffold`. The classes you actually use subclass them: `Flask(App)` in `app.py` and `Blueprint(SansioBlueprint)` in `blueprints.py`. They add the I/O side, such as running the WSGI app, pushing contexts, sending files and the test client.
