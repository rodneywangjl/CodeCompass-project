## Question

Why is the core app and blueprint code split into a separate `sansio` package instead of living in `app.py` and `blueprints.py`?

## Reference answer

So that async frameworks, specifically Quart, can build on the same core. Commit 0ec7f713 (pgjones, June 2023) split `App` and `Blueprint` into a sans-I/O part and an I/O part; the message says it "follows a similar structure in Werkzeug". The globals and signals stayed on the I/O side because they're specific to Flask's own I/O.
